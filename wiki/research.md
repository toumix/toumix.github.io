# Research

## Core interests

1. **Applied category theory** — using functors, monoidal categories, and string diagrams as a unifying mathematical language across linguistics, quantum computing, and AI.
2. **Compositional natural language processing** — giving formal, compositional semantics to language using DisCoCat (Distributional Compositional Categorical) models.
3. **Quantum computing & quantum machine learning** — near-term quantum NLP, diagrammatic differentiation, quantum-enhanced kernels.
4. **Artificial intelligence** — functorial language models, active inference, probabilistic dataflow, agent-based semantics.

## Key concepts and vocabulary

- **String diagrams** — graphical calculus for monoidal categories; the main representational tool in Alexis's work.
- **DisCoCat** — Distributional Compositional Categorical semantics; maps grammatical structure to vector space operations.
- **Monoidal categories / functors** — the categorical backbone; morphisms compose both sequentially and in parallel.
- **Quantum NLP (QNLP)** — running compositional NLP models on quantum hardware.
- **Diagrammatic differentiation** — backpropagation via string diagrams for hybrid quantum-classical ML.
- **Frobenius algebras** — used to model copying and discarding of information in quantum and linguistic settings.
- **Higher-order DisCoCat** — extends DisCoCat with Peirce-Lambek-Montague semantics for richer compositional meaning.
- **Active inference** — Bayesian framework for agents; applied using DisCoPy in recent work.
- **Probabilistic dataflow / monoidal streams** — categorical treatment of streaming and probabilistic computation.

## Methodological stance

Alexis's research is characterised by:
- Building software tools that make abstract mathematics computationally accessible (DisCoPy).
- Bridging theory and experiment: formal categorical models → quantum hardware implementation.
- Collaborating across mathematics, physics, linguistics and computer science.
